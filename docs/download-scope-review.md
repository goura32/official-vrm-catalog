# 登録凍結・人型ダウンロード選別レビュー（2026-10-08）

## 結論

- **追加の大量探索は1,297レコードでいったん終了**。件数目標を設けず、誤記・二重計上・配布状態・形状を精査する。
- カタログは人型・非人型を問わず情報を保持する。**永続保存の対象は人型モデルだけ**。外形不明のモデルは事前資料に限定せず、条件を満たせば一時取得して判定する。
- **人型**は外見上、頭・胴・両腕・両脚が人物に近いモデル。人間、亜人、二足の獣人、人型ロボット・人型モンスターは候補。「猫」「マスコット」「ちび」「ボクセル」等の単語やVRMのHumanoidリグだけでは人型/非人型を確定しない。
- 分類用IDリストは [data/download-scope.json](../data/download-scope.json) に独立保存し、既存カタログレコードを移動・削除・複写しない。
- このリストはページ名・商品説明等に基づく**予備分類**。登録されただけで実取得や永続保存の承認とはならない。リスト外IDは`pending_review`として**永続保存禁止**だが、公式・作者配布、無料条件・取得許諾を確認した場合に限り、形状確認のため一時取得できる。

## 実機検証の進め方（2026-10-08追補）

形状判定のみを独立した大量作業にしない。配布条件・入手成功・実ファイルの整合性と同時に処理する。

1. **配布根拠の確認**：公式・作者公開元、0円取得の可否、利用条件を確認。購入・NFT保有が必須、権利不明、認証回避が必要なものは保留。
2. **取得の要否**：明確な非人型は取得しない。人型候補と形状未判定は、配布条件を満たすなら一時領域へ入手する。画像があっても判別不能ならそこで止まらない。
3. **一度の実物検査**：VRM/ZIP構造、バージョン、重複ハッシュ、外形（必要なら3D表示）、権利メタデータを照合し、`humanoid_candidates` / `non_humanoid` / リスト外（保留）を更新する。**予備分類だけで取得成功や最終確認済みとは扱わない**。
4. **永続保管**：人型VRMだけを`/mnt/hdd/vrm/files/<catalog_id>.vrm.zst`へ**ロスレス圧縮**して保存する。元のZIP・非VRM同梱物は保存しない。非人型・保留・破損も保存せず、一時ファイルを消去する。
5. **記録**：取得日時、配布元URL、元ZIP名と内部VRMパス、利用条件URL、カタログID・モデル名、VRMバージョン、**未圧縮VRMのSHA-256**、圧縮前後のサイズ、保存パスを`index.jsonl`に記録する。判定情報は正本JSONとは別管理し、原本も圧縮実体もGitHubには置かない。手順は[NAS保存方式](nas-storage.md)。

## 重要な残課題と優先順位

1. **取得可否・権利**：BOOTHの0円配布と有料版・利用条件を区別し、実際の取得が必要な段階で確認する。公開索引のみの252件もNFT保有・有料認証が不要か確認。NeonGlitch86の許諾未確認分、Polygonal Mindのシリーズ別条件に注意。
2. **実体・重複**：ZIP内部の実VRM数、VRM規格版、配布ZIPの更新版との区別、同一ハッシュの重複を検査する。1 ZIP内の複数VRMは独立レコードとしてよく、URLやZIP名だけで削除・増加を断定しない。
3. **形状判定**：Polygonal Mindの各シリーズには人型と非人型が混在し得る。作者画像で容易に確定できるものは事前分類し、不明分は一時取得・3D表示で判断する。全1,002件の事前画像判定は完了条件にしない。
4. **暫定データ**：ぴケの創作屋さん14商品はZIP内の独立VRM数が未確認。Doll meの期間限定無料モデルの現行価格を再確認する。
5. **記録と保存**：非人型はカタログ情報のみ保持。人型VRMだけNASにzstd圧縮保存し、元ZIPに依存せずID・名称・取得元とハッシュを追跡できるようにする。
