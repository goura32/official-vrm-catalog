# 登録凍結・人型ダウンロード選別レビュー（2026-10-08）

## 結論

- **追加の大量探索は1,297レコードでいったん終了**。件数目標を設けず、誤記・二重計上・配布状態・形状を精査する。
- カタログは人型・非人型を問わず情報を保持する。**将来のダウンロード対象は人型モデルだけ**。
- **人型**は外見上、頭・胴・両腕・両脚が人物に近いモデル。人間、亜人、二足の獣人、人型ロボット・人型モンスターは候補。「猫」「マスコット」「ちび」「ボクセル」等の単語やVRMのHumanoidリグだけでは人型/非人型を確定しない。
- 分類用IDリストは [data/download-scope.json](../data/download-scope.json) に独立保存し、既存カタログレコードを移動・削除・複写しない。
- このリストはページ名・商品説明等に基づく**予備分類**。登録されただけで実取得の承認とはならない。外観の証拠が不足するIDは`pending_review`としてデフォルトでダウンロード禁止にする。

## 重要な残課題と優先順位

1. **形状判定**：Polygonal Mindの複数シリーズ計640件には人型と非人型が混在する可能性が高い。Halloween Rising、Xmas Chibis、R3はシリーズ名だけで一括採用しない。NeonGlitch86 36件・MJMoonbow 18件・その他の保留分も画像付きの制作者資料で分類する。
2. **取得根拠**：BOOTHの無料版と有料版・規約PDF等を区別。ZIP内の実VRM数、商品更新版とVRM仕様版の混同、共通商品URLとショップ固有URLの公開状態の矛盾を解消する。
3. **所有条件・権利**：公開索引のみの252件はNFT保有や有料の認証がなくても実VRMを取得できるか確認。NeonGlitch86の一部モデルではライセンスが未確認。Polygonal Mind R1/R2とR3の異なる許諾条件を混同しない。
4. **重複**：同じ`source_url`・`distribution_filename`が複数レコードに現れても、1 ZIP内の異なるVRMなら正当。ZIP内部のファイル名が確認できるまで削除も増加も断定しない。
5. **暫定データ**：ぴケの創作屋さん14商品はZIP内部の独立VRM数が未確認。Doll meの期間限定無料モデルも現在の価格を再確認する。非人型はカタログに残しても原本を取得しない。

## 登録拡充の終了条件

既知の主要配布元を収録できていることは「全インターネットの無料VRMの網羅」を意味しない。件数を増やす作業は**ここで凍結**し、明白な誤記の是正、公式・原作者から新たに発表された無料VRM、重要な既知の欠落の根拠が確認できたものだけ例外的に追加する。新規レコードは自動で`pending_review`に入り、ダウンロード対象にはならない。
